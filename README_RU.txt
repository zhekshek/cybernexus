NEXUS // NIGHT CITY OS — версия 1.4

Возможности
- Планировщик задач с HIGH / MED / LOW приоритетами
- Фильтры: все / активные / выполненные
- Сортировка задач
- Прогресс и статистика, XP за закрытие контрактов
- Focus Mode: таймер 25 минут, пауза/продолжение и 15 минут
- Пасхалка: нажми на логотип NEXUS три раза подряд
- Музыкальный поиск открывает результаты YouTube
- Экспорт резервной копии JSON
- Локальное сохранение задач в localStorage
- PWA-манифест и service worker для установки/офлайн-оболочки

ВАЖНО
Для установки PWA нужен HTTPS-хостинг (или localhost для разработки). Открытие index.html прямо из файлового менеджера не даст полноценную установку и service worker.

БЫСТРЫЙ ЗАПУСК НА ANDROID
1. Распакуй ZIP на компьютере.
2. Размести содержимое папки на статическом HTTPS-хостинге, который поддерживает обычные HTML-файлы (например, GitHub Pages или Netlify).
3. Открой HTTPS-ссылку в Chrome на Android.
4. Нажми меню ⋮ → «Установить приложение» или «Добавить на главный экран».
5. Подтверди. Иконка NEXUS появится на домашнем экране.

ЛОКАЛЬНЫЙ ЗАПУСК ДЛЯ ПРОВЕРКИ НА ПК
В каталоге проекта выполни:
  python -m http.server 8000
Затем открой http://localhost:8000 в браузере.
Этот localhost-режим годится для проверки service worker на том же компьютере, но не делает приложение доступным на телефоне автоматически.

СОХРАНЕНИЕ
Задачи сохраняются в localStorage конкретного браузера/установки на этом устройстве. Очистка данных браузера может удалить задачи. Используй «EXPORT BACKUP» в разделе СТАТЫ, чтобы скачать JSON-резервную копию. Облачной синхронизации нет.

ОГРАНИЧЕНИЯ
- Это самостоятельный статический PWA-прототип, не опубликованный в интернете.
- Встроенная музыка не поставляется; кнопка открывает поиск плейлистов.
- Таймер работает, пока приложение активно; браузер может приостанавливать таймер в фоне.
